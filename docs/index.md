# rebrickable 1.1

`rebrickable` is the typed, asynchronous data layer for the complete official
Rebrickable catalog, API v3, inventories, BOMs, and LDraw cross-referencing.
Catalog work is offline after an explicit refresh; ordinary session startup and
queries never contact the network.

Start with the [quickstart](quickstart.md), then use the focused references for
the [1.1 migration guide](migration-1.1.md), [catalog model](data-model.md),
[API](api.md), [CLI](cli.md), [LDraw bridge](ldraw-bridge.md), and [read-only TUI
integration](tui-integration.md).

This project does not download or render images and is not endorsed by LEGO or
Rebrickable.
